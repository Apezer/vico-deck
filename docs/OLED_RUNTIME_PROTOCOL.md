# OLED 运行时状态协议

Vico Keyboard 使用同一份 32 字节数据包，通过 USB Vendor HID 或自定义
BLE GATT RX 特征传输电脑运行状态。固件接收结构化数据后在本地绘制
128×64 OLED，避免持续发送完整帧缓冲区。

## 页面

| 编号 | 页面 | 用途 |
|---:|---|---|
| 0 | BRAND | Vico 品牌主页 |
| 1 | CODING | Claude Code 大状态、动画图标、工具、任务详情、会话数和活动时间 |
| 2 | SYSTEM | CPU、GPU、内存、温度和时间 |
| 3 | CLOCK | 时间、日期和星期 |
| 4 | DEVICE | 当前预设、连接模式和八个按键状态 |
| 5 | CUSTOM | 软件绘制或导入的 128×64 自定义像素画 |

## 数据包

所有包长度均为 32 字节：`0x56` 魔数、版本 `1`、包类型、负载和最后一字节
异或校验值。类型 `1` 状态包包含 Claude 状态、CPU/GPU/内存/温度百分比、
时间日期及最多 16 字节的工具名；类型 `6` 文本包包含最多 21 字节的任务详情、
活跃会话数和距离上次 Claude 活动的秒数。
拆分 `state / tool / text` 后，Coding 页面可以与参考 GATT 项目逐字段对齐。
类型 `2` 设置包包含默认页面和 Claude 自动覆盖开关。类型 `7` 为 RGB 设置包：
字节 3～6 依次为灯效编号（0～6，其中 6 为常亮）、亮度百分比（25～100）、
速度百分比（50～200）和总开关（0/1）；字节 7～9 为常亮模式的 R、G、B 颜色值。
RGB 包同样通过 USB `RUNTIME_UPDATE` 或 BLE RX
特征发送，固件即时应用，并在停止调整约 750ms 后合并写入一次 NVS。

自定义像素画使用类型 `3`（开始）、`4`（26 字节分片）和 `5`（提交）的包传输，
完整位图为 1024 字节，并使用 CRC32 校验。软件会串行发送这些包，避免 USB 或
BLE 写入交错；重新连接时会自动补发当前像素画。

### Coding 页面像素布局

- `y=0`：`CLAUDE CODE`、USB/BLE 连接方式与设备实测电量。
- `y=14`：大号工作状态；右侧显示 32×16 Claude 图标。
- `WORKING`：14 像素线段沿图标外围循环移动，固件约每 180ms 刷新一帧。
- `y=35`：当前工具或与状态对应的操作提示。
- `y=45`：最多 21 字符的任务详情。
- `y=55`：活跃会话数和距离上次 Claude 活动的时间。

USB 使用 Vendor HID 命令 `RUNTIME_UPDATE (0x40)`。BLE 使用服务
`7b6a0001-7c6e-4b3d-9f5f-7669636f0001` 的 RX 特征。设备端页面变化通过
USB 事件 `0x92` 或 BLE TX 通知返回软件。

## 更新策略

- CPU 和内存约每秒更新。
- GPU 通过 Windows 性能计数器每两秒尽力采集一次。
- 不支持的指标使用 `0xFF`，OLED 显示 `--`。
- Claude 工作、调用工具、等待或出错时可自动覆盖当前页面。
- Claude 完成提示保留约 5 秒，然后返回用户页面。
- 软件的“显示内容”下拉框与键盘端页面双向同步。
- 性能页面在软件预览和键盘 OLED 上使用同一组实时数据。
- USB 连接时软件通过 Vendor HID 握手及 `0x93` 事件获取电量和毫伏值；BLE 连接时通过标准 Battery Service 获取百分比。
