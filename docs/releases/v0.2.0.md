## VicoDeck 0.2.0

首个公开版本现已发布。

### 主要功能

- 8 个可编程按键的桌面配置界面
- 128×64 OLED Studio 实时预览
- 多配置文件与本地自动保存
- Windows 系统托盘和开机自启动
- Claude Code hooks 后台状态监听
- 通过 BLE GATT 将 Claude Code 状态转发到 ESP32-S3 OLED
- USB WebHID 配置协议草案

### Claude Code Relay

软件可以显示并转发以下事件：

- 会话开始与结束
- 用户提交任务
- 正在调用工具
- 工具完成或失败
- 等待用户处理
- 任务完成

### 安装提示

下载 `VicoDeck-Setup-Windows.exe` 后运行安装程序。当前版本尚未进行商业代码签名，Windows SmartScreen 可能显示未知发布者提示。

- Vite 生产构建通过
